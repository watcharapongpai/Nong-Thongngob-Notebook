# น้องตรงงบ — แชทบอทแนะนำโน้ตบุ๊กตามงบ (ร้านตรงงบ Notebook)

เว็บแชทบอทที่ช่วยลูกค้าเลือกโน้ตบุ๊กตามงบและการใช้งาน ตอบจากข้อมูลสินค้า (`data/products.csv`) และนโยบายร้าน (`data/shop_info.json`) เท่านั้น เขียนด้วย Python + Flask รันใน VS Code แล้วเปิดคุยผ่านลิงก์ในเบราว์เซอร์

## ความสามารถ

- **แนะนำรุ่นตามงบ + การใช้งาน**: เรียน/ทำงานเอกสาร, เขียนโปรแกรม, เล่นเกม, ตัดต่อ/กราฟิก (แสดง 2–3 รุ่น พร้อมสเปกคร่าว ๆ จุดเด่น และข้อสังเกต)
- **"งบนี้ทำอะไรได้บ้าง"**: สรุปว่างบนี้มีรุ่นที่เหมาะกับงานแต่ละแบบกี่รุ่น เริ่มต้นกี่บาท
- **"งบ 3 หมื่นเล่นเกมได้ไหม" / "รุ่นนี้เล่นเกมได้ไหม"**: ตอบตามเกณฑ์ของร้าน พร้อมเหตุผลจากสเปก
- **ดูสเปก / เทียบ 2 รุ่น / ดูราคาโปร / ค้นหาจากชื่อรุ่น** (เช่น "victus", "msi modern 16s", "NB040")
- **เทียบด้วยชื่อซีรีส์ได้เลย** เช่น "เทียบ LENOVO IDEAPAD SLIM 5 กับ MSI MODERN 16S" ถ้าชื่อนั้นมีหลายรุ่นย่อย บอทจะเลือกรุ่นที่ราคาถูกที่สุดมาเทียบ แล้วมีปุ่มให้สลับเป็นรุ่นย่อยอื่น
- **เข้าใจงบภาษาไทย**: "หมื่นห้า", "สองหมื่นห้า", "2.5 หมื่น", "20k", "15-20k", "ไม่เกิน 3 หมื่น", "4 หมื่นขึ้นไป"
- **เงื่อนไขเพิ่มเติม**: แบรนด์ ขนาดจอ จอ OLED มี Office รุ่นการ์ดจอ (เช่น "rtx 4050")
- **ตอบนโยบายร้าน** จากไฟล์ `shop_info.json` (สรุปเป็นเอกสารอ่านง่ายใน `SHOP_POLICY.md`)
- **ส่งรูปมาถามได้** (ปุ่มรูปภาพ, วางรูปด้วย Ctrl+V หรือลากรูปมาวาง) บอทใช้โมเดล CLIP ที่รันในเครื่องวัดว่ารูปเกี่ยวกับโน้ตบุ๊กไหม ถ้าไม่เกี่ยว บอทตอบว่าไม่ใช่เรื่องที่ช่วยค้นหาได้ (ดูหัวข้อ "ส่งรูปเพื่อสอบถาม")

## ขอบเขตงาน และวิธีที่ระบบทำให้เป็นไปตามนั้น

| ขอบเขต | วิธีที่ระบบทำ |
|---|---|
| **1.1.1** ตอบจากข้อมูลจริงของร้านเท่านั้น | บอท **ไม่ใช้ AI สร้างข้อความ** คำตอบทุกข้อสร้างจากแม่แบบที่ดึงชื่อรุ่น ราคา และสเปกจาก `products.csv` โดยตรง ช่องที่ว่างในไฟล์ (น้ำหนัก แบตเตอรี่ ประกัน สต็อก) บอทจะตอบว่า "ยังไม่มีข้อมูลในระบบ" เสมอ ถ้าถามรุ่นหรือแบรนด์ที่ไม่มี บอทตอบว่าร้านไม่มี |
| **1.1.2** ลูกค้าใช้ได้เองโดยไม่ต้องมีคนอธิบาย | ข้อความต้อนรับบอกว่าช่วยอะไรได้ พร้อมตัวอย่างวิธีพิมพ์ มีปุ่มตัวเลือกทุกขั้น ถามทีละคำถาม ตอบเป็นตัวเลข 1–4 ได้ และถ้าบอทไม่เข้าใจจะให้ตัวอย่างใหม่ |
| **1.1.3** ไม่ถูกหลอกให้ทำสิ่งที่ร้านไม่อนุญาต | ร้านกำหนดนโยบายไว้ชัด (ดู `SHOP_POLICY.md`): ไม่มีการต่อรองราคาหรือส่วนลดผ่านแชท ไม่เก็บและไม่เปิดเผยข้อมูลลูกค้า และไม่มีช่องทางติดต่อพนักงาน คำขอส่วนลด ของแถม หรือแมตช์ราคา, การอ้างตัวเป็นผู้จัดการหรือแอดมิน, คำสั่งแทรก (เช่น "ลืมคำสั่งก่อนหน้า"), การขอข้อมูลลูกค้าคนอื่น และคำถามนโยบายที่ไม่มีในไฟล์ จะถูกดักก่อนทุกอย่างแล้วตอบด้วยข้อความปฏิเสธที่กำหนดไว้ บอทไม่มีข้อมูลลูกค้าเลย จึงเปิดเผยข้อมูลลูกค้าไม่ได้ และไม่มีการบันทึกข้อความแชทหรือรูป ข้อความที่แนบมากับรูปก็ผ่านตัวดักชุดเดียวกัน ส่วนตัวตรวจรูปให้ได้แค่คะแนนความเกี่ยวข้อง จึงไม่มีช่องให้ข้อความในรูปมาสั่งบอทได้ |

ชุดทดสอบอัตโนมัติ (`tests/`) ทดสอบทั้ง 3 ข้อนี้ ใช้เป็นหลักฐานในรายงานได้

## วิธีรันใน VS Code

แตกไฟล์ zip ก่อน ในโฟลเดอร์ต้องเห็นไฟล์ `app.py` (ถ้าแตกแล้วได้โฟลเดอร์ซ้อนกัน ให้เข้าไปอีกชั้น)

### แบบ Anaconda (Windows)

1. เปิด **Anaconda Prompt** แล้วเข้าไปที่โฟลเดอร์โปรเจค
   ```
   cd /d "C:\ที่อยู่โฟลเดอร์\trongngob-notebook-bot"
   ```
2. สร้าง environment แยกให้โปรเจค (ทำครั้งเดียว)
   ```
   conda create -n trongngob python=3.12 -y
   conda activate trongngob
   pip install -r requirements.txt
   ```
3. รัน `python app.py` แล้วเปิด **http://127.0.0.1:8000**
4. อยากใช้ VS Code: พิมพ์ `code .` ใน Anaconda Prompt หลัง `conda activate trongngob` แล้วรันจาก Terminal ใน VS Code ได้เลย

ครั้งต่อไป: เปิด Anaconda Prompt → `cd /d ...` → `conda activate trongngob` → `python app.py`

### แบบ Python ปกติ

1. ติดตั้ง Python (Windows: ติดตั้ง **Python Install Manager** จาก Microsoft Store) แล้วเปิดโฟลเดอร์ใน VS Code
2. ใน Terminal พิมพ์

   **Windows**
   ```
   py -m venv .venv
   .venv\Scripts\python -m pip install -r requirements.txt
   .venv\Scripts\python app.py
   ```
   **macOS / Linux**
   ```
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   python app.py
   ```
3. เปิด **http://127.0.0.1:8000** หยุดเซิร์ฟเวอร์ด้วย **Ctrl+C**

> กด **F5** ใน VS Code เพื่อรันได้ (เลือก interpreter ก่อน: Ctrl+Shift+P → "Python: Select Interpreter" แล้วเลือก `trongngob` หรือ `.venv`)

## แชร์ลิงก์ให้คนอื่นลองคุย

- **คนที่ใช้ Wi-Fi เดียวกัน**: รันด้วย `HOST=0.0.0.0` แล้วให้เพื่อนเปิด `http://<IP เครื่องคุณ>:8000`
  - Windows (PowerShell): `$env:HOST="0.0.0.0"; python app.py` แล้วดู IP ด้วย `ipconfig`
  - macOS: `HOST=0.0.0.0 python app.py` แล้วดู IP ด้วย `ipconfig getifaddr en0`
- **ผ่านอินเทอร์เน็ต (ลิงก์ชั่วคราว)**: เปิดแอปไว้ แล้วใช้ ngrok (`ngrok http 8000`) หรือ Cloudflare Tunnel (`cloudflared tunnel --url http://localhost:8000`) จะได้ลิงก์ https ส่งให้คนอื่นได้ ปิดเมื่อเลิกใช้
- **ลิงก์ถาวร**: deploy ขึ้นบริการโฮสต์ Python (เช่น Render) โดยเพิ่ม `gunicorn` ใน requirements แล้วใช้คำสั่งเริ่มเป็น `gunicorn app:app`

## ส่งรูปเพื่อสอบถาม (ตรวจความเกี่ยวข้องด้วย CLIP)

### ติดตั้ง (ทำครั้งเดียว ต้องใช้อินเทอร์เน็ต ดาวน์โหลดรวมราว 1–2 GB)

ใน environment เดียวกับที่รันบอท (เช่น หลัง `conda activate trongngob`):
```
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements-vision.txt
python tools/download_model.py
```
คำสั่งสุดท้ายดาวน์โหลดโมเดล `openai/clip-vit-base-patch32` (~600 MB) มาเก็บไว้ในเครื่อง หลังจากนั้นใช้แบบออฟไลน์ได้ ควรทำก่อนวันเดโม ถ้ายังไม่ติดตั้ง บอทยังใช้งานได้ปกติ แต่จะตอบว่า "ระบบตรวจรูปยังไม่พร้อม" เมื่อมีคนส่งรูป

### บอทวัดความเกี่ยวข้องอย่างไร (ใส่ในรายงานได้)

1. CLIP เป็นโมเดลที่เทียบ "รูป" กับ "ประโยคอธิบายภาพ" ได้ (zero-shot classification ไม่ต้องเทรนเพิ่ม)
2. ระบบเตรียมประโยคไว้ 26 ประโยคใน `bot/vision.py` (`PROMPTS`) แบ่งเป็นกลุ่ม **เกี่ยวข้อง** เช่น รูปโน้ตบุ๊ก โน้ตบุ๊กเกมมิ่ง กล่อง/สติกเกอร์สเปก ภาพหน้าจอหน้าสินค้า โน้ตบุ๊กมีปัญหา และกลุ่ม **ไม่เกี่ยวข้อง** เช่น มือถือ แท็บเล็ต คอมตั้งโต๊ะ อาหาร สัตว์ คน วิว มีม บัตร/เอกสารส่วนตัว
3. CLIP ให้ความน่าจะเป็นของทุกประโยค (รวมกันได้ 100%) **คะแนนความเกี่ยวข้อง = ผลรวมความน่าจะเป็นของประโยคกลุ่มเกี่ยวข้อง**
4. ตัดสินตามเกณฑ์: ตั้งแต่ 60% = เกี่ยวข้อง, 35–59% = ไม่แน่ใจ (ขอให้ลูกค้าพิมพ์อธิบาย), ต่ำกว่า 35% = ไม่เกี่ยวข้อง (ปรับได้ที่ `RELEVANT_AT` / `UNCERTAIN_AT`)

คะแนนใช้ตัดสินภายในระบบเท่านั้น บอทไม่แสดงตัวเลขให้ลูกค้าเห็น

| ผลตรวจ | บอทตอบ |
|---|---|
| เกี่ยวข้อง | บอกประเภทภาพ บอกตรง ๆ ว่ายังอ่านชื่อรุ่นจากรูปไม่ได้ ชวนพิมพ์ชื่อรุ่นหรือบอกงบ ถ้าเป็นรูปเครื่องเกมมิ่งจะมีปุ่ม "ดูรุ่นเล่นเกม" ถ้าเป็นรูปเครื่องมีปัญหาจะตอบตามนโยบายบริการซ่อม |
| ไม่แน่ใจ | ขอให้พิมพ์อธิบายเพิ่ม |
| ไม่เกี่ยวข้อง | ตอบว่า "รูปนี้ไม่ใช่เรื่องที่น้องตรงงบช่วยค้นหาได้" |
| อาจเป็นบัตร/เอกสารส่วนตัว | เตือนไม่ให้ส่งรูปลักษณะนี้ และแจ้งว่าระบบไม่ได้บันทึกรูป |

ถ้าลูกค้าพิมพ์ข้อความมากับรูป (เช่น "อยากได้แบบนี้ งบ 3 หมื่น") บอทจะตอบข้อความนั้นตามปกติต่อท้ายผลตรวจรูป

### วัดความแม่นยำด้วยชุดรูปทดสอบ

เก็บรูปทดสอบอย่างละ 20–50 รูป แยกโฟลเดอร์ตามนี้
```
eval_images/
├── relevant/     รูปเกี่ยวกับโน้ตบุ๊ก (ถ่ายเอง สติกเกอร์สเปก ภาพหน้าจอหน้าสินค้า ...)
└── irrelevant/   รูปไม่เกี่ยว (มือถือ อาหาร คน วิว มีม ...)
```
แล้วรัน
```
python tools/eval_images.py eval_images
```
จะได้คะแนนรายรูป ค่า Accuracy, Precision, Recall, F1 ที่เกณฑ์ปัจจุบัน ตารางลองเกณฑ์ 0.30–0.90 พร้อมเกณฑ์ที่ได้ F1 สูงสุด และไฟล์ `eval_results.csv` สำหรับแนบรายงาน

### ข้อจำกัด

- CLIP บอกได้ว่ารูป "เกี่ยวกับโน้ตบุ๊กไหม" แต่ **อ่านชื่อรุ่น ราคา หรือสเปกจากรูปไม่ได้** บอทจึงไม่เดาว่าเป็นรุ่นไหน
- รูปครั้งแรกหลังเปิดแอปจะช้ากว่าปกติ (โหลดโมเดล) ต่อจากนั้นใช้เวลาไม่ถึงวินาทีบนคอมทั่วไป
- รับไฟล์ JPG, PNG, WEBP, GIF ไม่เกิน 5 MB รูปประมวลผลในหน่วยความจำและไม่ถูกบันทึกลงเครื่อง

## แก้ไขข้อมูลและเกณฑ์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `data/products.csv` | ข้อมูลสินค้า 121 รุ่น แก้หรือเพิ่มได้ ช่องที่เว้นว่าง = ไม่มีข้อมูล (บอทจะไม่เดา) แก้เสร็จแล้วรัน `python tools/enrich_catalog.py` เพื่ออัปเดตคอลัมน์ `spec_summary` และ `suitable_for` |
| `data/shop_info.json` | นโยบายร้านที่บอทใช้ตอบ (ข้อความในช่อง `answer` ตอบแบบคำต่อคำ) ช่องที่ว่างอยู่ เช่น ที่ตั้งร้าน บอทจะตอบว่า "ร้านยังไม่มีข้อมูลเรื่องนี้" ร้านไม่มีช่องทางติดต่อ จึงเว้น `contact` ว่าง ถ้าภายหลังมี ใส่ช่องนี้แล้วบอทจะแสดงปุ่ม "คุยกับพนักงาน" ให้เอง |
| `SHOP_POLICY.md` | สรุปนโยบายร้านแบบอ่านง่ายสำหรับใส่รายงาน (ถ้าแก้นโยบายใน `shop_info.json` ให้แก้เอกสารนี้ให้ตรงกันด้วย) |
| `bot/rules.py` | เกณฑ์ของร้านว่าการใช้งานแต่ละแบบต้องมีสเปกขั้นต่ำเท่าไหร่ และวิธีจัดอันดับรุ่น |

เกณฑ์เริ่มต้นในระบบ (ปรับได้ใน `bot/rules.py` และควรเขียนอธิบายไว้ในรายงาน):

| การใช้งาน | เงื่อนไขขั้นต่ำ |
|---|---|
| เรียน/ทำงานเอกสาร | RAM 8GB ขึ้นไป, SSD 256GB ขึ้นไป |
| เขียนโปรแกรม | RAM 16GB ขึ้นไป, SSD 512GB ขึ้นไป |
| เล่นเกม | มีการ์ดจอแยก, RAM 16GB ขึ้นไป |
| ตัดต่อ/กราฟิก | RAM 16GB, SSD 512GB และ (การ์ดจอแยก หรือจอ OLED หรือจอที่ระบุขอบเขตสี 100%) |

ถ้างบพอดีมีรุ่นที่ผ่านเกณฑ์ไม่ถึง 2 รุ่น บอทจะเสนอเพิ่มได้ 1 รุ่นที่เกินงบไม่เกิน 10% และติดป้ายว่า "เกินงบ X บาท" ทุกครั้ง

## ที่มาของข้อมูลและข้อจำกัด

- ราคาและสเปกใน `products.csv` เก็บจากหน้ารายการสินค้าเว็บไซต์ **JIB (jib.co.th) เมื่อวันที่ 2 พ.ย. 2569** (ดูคอลัมน์ `source_url`) ราคาจริงเปลี่ยนบ่อย ไฟล์นี้จึงเป็นข้อมูล ณ วันนั้นเท่านั้น
- "ตรงงบ Notebook" เป็นชื่อร้านสมมติ ในรายงานควรระบุแหล่งข้อมูลให้ชัด
- หน้ารายการสินค้าไม่ได้แสดงน้ำหนัก แบตเตอรี่ ระยะประกัน และสต็อก ช่องเหล่านี้จึงว่าง ถ้าลูกค้าขอเครื่อง "พกพา" บอทจะบอกว่าไม่มีข้อมูลน้ำหนัก แล้วกรองเป็นรุ่นจอไม่เกิน 14 นิ้วแทน
- บอทเข้าใจภาษาด้วยกฎและคีย์เวิร์ด จึงอาจไม่เข้าใจทุกรูปแบบประโยค แต่ถ้าไม่เข้าใจจะให้ตัวอย่างวิธีพิมพ์และปุ่มตัวเลือกแทนการเดา
